# لوحة المعلم — كيفية الاستخدام

1. افتح الملف `index.html` في أي متصفح (يعمل من القرص مباشرة بلا سيرفر)،
   أو ارفعه على أي استضافة / GitHub Pages كمستودع خاص.
2. أدخل **مفتاح المعلم** (TEACHER_KEY من Apps Script ← Project Settings،
   أو من قائمة 📊 Tracking في الورقة ← Run setup / get teacher key).
3. ستظهر لوحة المتابعة: إحصاءات، رسم نشاط 30 يومًا، جدول الطلاب،
   مصفوفة الإكمال، تحليل الأسئلة، آخر النشاطات، وتصدير CSV.

- رابط ورقة التتبع مثبّت داخل الملف؛ لتغييره (نسخة احتياطية مثلًا):
  زر ⚙ بجوار حقل المفتاح ← عدّل الرابط ← حفظ.
- المفتاح والرابط يُحفظان في متصفحك أنت فقط (localStorage).
- تبديل اللغة EN / عربي من الزر أعلى الشاشة.
- هذا الملف **لك وحدك** — لا ترسله للطلاب ولا تضعه في مستودع عام.
